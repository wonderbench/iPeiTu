# iPeiTu

Windows WPS 文字的本地标书配图工具。导入图片后，可按名称检索、预览，并将所选图片插入当前光标位置。

## 启动

需要 Windows、WPS 文字和 Node.js 24 或更新版本。已实测 WPS `12.1.0.29161`。

在项目目录打开 PowerShell，安装依赖并启动图库服务：

```powershell
npm ci
npm start
```

保持该窗口运行，在另一个 PowerShell 窗口、同一项目目录注册加载项：

```powershell
npm run wps:install
```

保存正在编辑的文档，关闭并重新打开 WPS 文字。选择功能区 **iPeiTu 配图 → 打开素材库**。

也可在浏览器打开 [本地图库预览](http://127.0.0.1:39831/taskpane.html)。浏览器支持导入、检索和预览；插入文档需从 WPS 内打开。

## 使用

1. 点击“导入素材”，选择一张或多张图片；也可粘贴完整文件夹路径，递归导入子文件夹。
2. 输入名称、别名或工序标签进行检索，空格分隔的多个词需要同时匹配。点击“筛选”可再筛选分类、未分类和多个标签。
3. 点击缩略图选择素材；点击底部小图可放大预览，按 Esc 关闭。
4. 按需要打开底部“排版设置”，选择自适应或固定宽度、最大高度、独立段落居中和图题。设置保存在本机，图题可以编辑；切换图片会重新取图片名称，不沿用上一张图的自定义文字。
5. 在 WPS 文档中放置光标，点击“插入光标处”。若选中了文字，图片插在选区末端，原文字保留。

“全部 / 收藏 / 最近”可切换图库视图，也可以继续搜索和筛选。选择图片后点击“收藏”保存；“最近”保留最多 100 张成功插入的图片，同图更新到最前。预览和插入失败不计入最近；如果图片已插入而记录保存失败，会分别提示，避免重复插图。

Tab 可进入图库，方向键移动选择，Home / End 选首尾图片，Enter / 空格只选图。插入需聚焦“插入光标处”按钮后执行。

选择图片后可打开“素材信息”编辑名称、别名、分类和标签；列表每行一项，留空可清除。修改保存在图库，不重命名原始素材文件。文件夹导入会保留相对目录分类；根目录图片使用该文件夹名称，重复图片合并别名与分类。

支持 PNG、JPEG、静态 WebP；单张不超过 32 MB、6400 万像素。损坏或不支持的文件会列出失败原因，其余有效图片继续导入。

图片以独立的内嵌对象插入。默认自适应模式只缩小；固定宽度模式可放大小图，始终保持比例并受页面/单元格可用宽度及可选最大高度限制。居中或图题会创建独立图片段落，图题是普通文字，不自动编号。插入后可继续插入下一张，插件不自动保存文档。

在 WPS 正文中选中一张内嵌图片，再从图库选择素材，点击“替换选中图”，即可保留原位置、实际宽度和相邻文字。新图按自身比例调整高度，替换不使用插图排版设置，也不改原图题；不迁移裁剪、滤镜等图片特效。一次撤销可恢复原图。

## 本地图库与再次启动

导入会复制原图到 `%LOCALAPPDATA%\iPeiTu\library`，不移动或修改源文件。相同内容只保存一条素材记录，不同文件名保留为可检索别名。缩略图、索引和必要的 WPS 插入副本也保存在该目录；WebP 和带方向信息的照片会生成用于插入的 PNG。

iPeiTu 的导入、检索和插图使用本机回环服务，不上传素材到云端。图库不随代码提交到仓库。

首次使用新版会把旧索引升级到版本 2，并先在图库目录生成 `index-v1-backup-*.json` 原字节备份。既有图片、名称和别名保持不变，旧图片先归为“未分类”。未知版本或损坏索引会报错并保留原文件。

收藏与最近记录独立保存在图库目录的 `usage.json`，重启后保留。备份图库时请复制整个图库目录；记录文件损坏会明确报错，不自动清空。

关闭服务窗口或按 Ctrl+C 后，图库暂时不可访问。下次使用时在项目目录运行 `npm start`，再从 WPS 打开素材库；已有素材保留，不必重新导入或重复注册。重启电脑后也按此方式启动。

卸载加载项注册：

```powershell
npm run wps:uninstall
```

卸载后重启 WPS 生效；脚本仅移除本次注册并恢复原有同名条目，不删除图库，也不覆盖其他加载项的配置。注册与备份机制见 [WPS 说明](docs/WPS.md)。

## 验证

```powershell
npm run check
npm test
npx playwright install chromium
npm run test:ui
```

Windows 若已安装 Microsoft Edge，可用它运行界面测试：

```powershell
$env:IPEITU_BROWSER_CHANNEL = 'msedge'
npm run test:ui
```

界面测试会启动独立的临时图库，不修改日常素材。WPS 自动化测试采用模拟宿主，实机结果单独记录于 [验收记录](docs/ACCEPTANCE.md)。

## 当前支持范围

本版采用本地开发注册，服务端口为 `39831`，尚不是独立安装包；使用时需要保持本机服务运行。目标宿主为 Windows WPS 文字，不包含 Microsoft Word、WPS 演示或在线文档适配。

本版不自动调整固定表格行高、分栏、文本框、复杂嵌套表格或段落缩进。团队云图库与表格占位配图将按后续计划逐步交付。

当前插入与替换支持正文及正文表格。页眉、页脚、文本框等区域会明确禁用，避免不同文字区域具有相同坐标时误判目标；替换暂不支持浮动图片、多图或包含相邻文字的选区。
