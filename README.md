# iPeiTu

Windows WPS 文字的本地标书配图工具：管理本地图片素材，在文档中放置占位框并按框的尺寸填入图片（可裁切、拉伸或完整显示），并提供一键排版、表格宽度整理和标书知识库（通用文字片段的分类维护与插入）。可以只在本机使用，也可以让一台电脑作为局域网图库服务器，与同事共用素材和知识库。

## 启动

需要 Windows 和 WPS 文字。已实测 WPS `12.1.0.29161`。

### 一键安装

在项目文件夹中双击 **安装.cmd**，按窗口提示完成以下步骤。

1. 检查 Node.js 和 npm。已有可用的 Node.js 24 或更新版本时直接使用，否则在 x64 或 ARM64 Windows 上下载并校验 Node.js 官方便携版，存到 `%LOCALAPPDATA%\iPeiTu\runtime`。
2. 安装运行所需的依赖。已有依赖能正常加载时跳过。
3. 注册 WPS 加载项。
4. 设置登录 Windows 后自动在后台启动本地图库，并立即启动。

首次下载运行环境和依赖需要联网。便携版由 iPeiTu 自动查找，系统 PATH 保持原样。安装完成后保存正在编辑的文档，关闭并重新打开 WPS 文字，选择功能区 **iPeiTu 配图 → 打开素材库**。

| 文件 | 用途 |
| --- | --- |
| 启动.cmd | 在后台启动本地图库；已在运行时不会再开一个 |
| 停止.cmd | 停止本目录启动的本地图库，更新代码前先停止 |
| 卸载.cmd | 停止服务、移除自动启动、还原 WPS 加载项注册；素材图库保留 |
| 局域网服务器.cmd | 安装并把本机作为局域网图库服务器，见[局域网部署](#局域网部署) |

本地图库在后台运行，没有窗口，日志在 `%LOCALAPPDATA%\iPeiTu\logs`。端口 39831 被其他程序占用时，启动会报出占用的程序并停止，不影响那个程序。停止和卸载只结束由本目录 `server\index.js` 启动的进程。也可以在项目目录运行 `npm run setup`、`npm run service:start`、`npm run service:stop`、`npm run service:status`、`npm run remove`。

### 手动启动（开发用）

在项目目录打开 PowerShell，安装依赖并启动图库服务：

```powershell
npm ci
npm start
```

保持该窗口运行，在另一个 PowerShell 窗口、同一项目目录注册加载项：

```powershell
npm run wps:install
```

保存正在编辑的文档，关闭并重新打开 WPS 文字。选择功能区 **iPeiTu 配图 → 打开素材库**。

启动 iPeiTu 服务后，双击 **打开网页版管理端.url**，或在浏览器打开 [iPeiTu 资源管理](http://127.0.0.1:39831/manage.html)。素材管理支持导入、检索、预览、分类标签、批量整理及回收站；知识库管理支持新建、编辑、分类筛选及恢复片段。浏览器和 WPS 使用同一图库来源，切换来源可在素材管理的「本机」或「局域网」按钮中完成。插图、插入片段和从文档收录内容仍在 WPS 任务窗格中操作。

切回 WPS 窗格或网页管理模块时，素材和知识库列表会重新读取已保存的数据。编辑框打开期间会延后列表刷新，保存或取消后再更新。

## 使用

1. 点击“导入素材”，选择图片或文件夹；也可展开“输入路径”粘贴完整目录路径，或直接把图片文件拖进窗格、在窗格中粘贴截图（按时间命名为“粘贴图片-日期-时间”）。导入过程中可查看进度，失败项可单独重试。
   在浏览器管理页选择文件夹时，iPeiTu 会显示导入确认框。可浏览文件夹并查看图片数量，也可粘贴本机文件夹路径后确认导入。
2. 输入名称、别名或工序标签进行检索，空格分隔的多个词需要同时匹配。检索框下方的分类按钮直接点选分类或未分类；点击“筛选”可再按比例（横图、竖图、方图）和多个工序标签筛选。
3. 点击缩略图选择素材；窄窗格在底部、宽窗口在右侧显示所选图片，点击该图可放大预览，按 Esc 关闭。
4. 按需要打开“排版设置”，选择自适应或固定宽度、最大高度、独立段落居中和图题。设置保存在本机，图题可以编辑；切换图片会重新取图片名称，不沿用上一张图的自定义文字。
5. 在 WPS 文档中放置光标，将鼠标移到图片卡片上，点击“插入文档”。触屏上先点图片卡片即可显示操作。若选中了文字，图片插在选区末端，原文字保留。

“全部 / 收藏 / 最近”可切换图库视图，也可以继续搜索和筛选。选择图片后点击“收藏”保存；“最近”保留最多 100 张成功插入的图片，同图更新到最前。预览和插入失败不计入最近；如果图片已插入而记录保存失败，会分别提示，避免重复插图。

Tab 可进入图库，方向键移动选择，Home / End 选首尾图片，Enter / 空格只选图。要插入时按 Tab 进入当前卡片的“插入文档”按钮，再按 Enter。再按一次 Tab 可进入收藏按钮。

选择图片后可打开“素材信息”编辑名称、别名、分类和标签；列表每行一项，留空可清除。修改保存在图库，不重命名原始素材文件。需要一次整理多张时，点击“多选”后勾选图片（可“全选当前”），再点“设置分类与标签”批量添加或移除分类和工序标签；所有图片都能修改时才保存，任何一张有问题都不改。文件夹导入会保留相对目录分类；根目录图片使用该文件夹名称，重复图片合并别名与分类。

网页管理端和 WPS 共用素材信息编辑锁。打开编辑框时读取最新信息并锁定该图片，保存或取消后释放。其他人仍可预览和插入图片。批量设置遇到锁定的图片时会提示图片名称，整批修改都不保存。

将素材移到回收站后，可以预览或恢复。恢复时保留原有名称、分类、收藏和最近使用记录。同内容素材再次导入也会恢复原记录。

素材回收站列表上方提供「清空回收站」。弹窗显示全部待删除素材的数量，确认后会清空回收站，包括筛选条件之外的素材。

在 WPS 素材库和浏览器管理页，选中单张图片后可在详情区直接点「移到回收站」。按住 Ctrl 点击图片可增减选中的素材，批量操作在列表上方。回收站也支持 Ctrl 多选。选中单张或多张后点「永久删除」，确认后会移除图库里的图片、缩略图和随原图保存的兼容副本，无法从回收站恢复。导入来源文件和已插入文档的图片仍可继续使用。此前生成的适配、压缩和局域网下载缓存独立保存。

目录导入由本地服务执行，查询中断时点击“继续查看”读取同一任务，不会重新导入。任务报告保留最多 20 份、完成后一小时内可用；服务重启后报告失效，已导入的图片仍保留。单个目录任务最多扫描 10000 个文件与目录、记录 1000 个失败项，达到上限时明确停止并说明已处理范围。文件选择产生的失败重试依赖当前页面保留的文件引用，刷新页面后需重新选择文件。

支持 PNG、JPEG、静态 WebP；单张不超过 32 MB、6400 万像素。损坏或不支持的文件会列出失败原因，其余有效图片继续导入。

图片以独立的内嵌对象插入。默认自适应模式只缩小；固定宽度模式可放大小图，始终保持比例并受页面/单元格可用宽度及可选最大高度限制。居中或图题会创建独立图片段落，图题是普通文字，不自动编号。插入后可继续插入下一张，插件不自动保存文档。

在 WPS 正文中选中一张内嵌图片，再从图库选择素材，点击“替换选中图”，即可保留原位置、实际宽度和相邻文字。新图按自身比例调整高度，替换不使用插图排版设置，也不改原图题；不迁移裁剪、滤镜等图片特效。一次撤销可恢复原图。

## 占位框

点击顶部“占位框”，填写框名并选择尺寸，可在光标处插入一个灰色虚线框，标出待配图的位置。尺寸可选整行宽（4:3）、横向 12 × 9 厘米、竖向 9 × 12 厘米、填满单元格或自定义宽高；超出页面或单元格时等比缩小，自动行高的单元格按 4:3 取高。

正文中的框独立成段、居中、单倍行距，前后文字和段落格式不变；光标在空段落或空单元格时直接放入，不多加空行。一次撤销可移除。

面板列出当前文档中的全部占位框，点击即选中定位；文档改动后点击“重新扫描”。框名和尺寸写在图片的替代文字中。未填的框会随文档打印，交付前请检查。

在文档中选中一个占位框（或在列表中点击定位），窗格底部会显示目标框和尺寸，图片卡片的插入按钮会显示“填入占位框”。适配方式可选：

- 裁切填满（默认）：铺满框，超出部分居中裁掉，不变形。
- 拉伸填满：铺满框，内容完整，可能变形。
- 完整显示：内容完整，空白处补白，不变形。

三种方式都按框的宽高设定图片尺寸，WPS 可能产生不足 1 磅的尺寸偏差。适配图按框的尺寸和“排版设置”中的图片质量生成（原图 300、清晰 220、均衡 150 dpi），不超过原图分辨率，原始素材不修改。填入后框名保留，可以再次选中换图；一次撤销可恢复原框。“按框名检索”会把框名填入检索框。选中占位框时不显示“替换选中图”，以免丢失框的标记。

连续配图：

- 填入后自动选中下一个空框，点击下一张图的“填入占位框”继续；后面没有空框时从文档开头找，全部填完会提示。
- “比例接近优先”打开后，比例与所选框接近的图片排在前面；关闭后恢复原顺序。
- 占位框列表显示未填数量，“只看未填”只列出空框。
- “查找文字标记”找出正文中 `【图：名称】`（冒号可为全角或半角）的文字，列出后点击“按上方尺寸转为占位框”，标记会被同名占位框替换，其他文字不变；一次撤销可恢复。
- 交付前点击“清除标记”，确认后清除已填框的插件标记，图片保留；清除后这些图片不能再按框换图。未填的框不清除，会提示数量，请先填入或删除。

“排版设置”中的图片质量用于插入和替换：默认“原图”使用原有插入文件；“清晰”长边最多 2400 像素，“均衡”长边最多 1600 像素。小图不放大，透明图保留透明度，原始素材不修改。处理结果会缓存，同一图片再次使用相同档位可复用；小图或原本压缩充分的图片不保证文件更小。

压缩档会清除原图的个人元数据，并尽量保持插入时的自然宽度；无法可靠解释分辨率声明时会提示改用原图。压缩档已通过自动化与浏览器验收，真实 WPS 的尺寸和替换效果仍待验收，详见 [图片质量验收记录](docs/QUALITY-ACCEPTANCE.md)。

## 排版工具

功能区 **iPeiTu 配图 → 排版工具** 打开独立的任务窗格，点击即执行：

- 段落：清除格式、首行缩进（2 字符）、居中对齐。
- 表格：表格满页、边距清零（并固定列宽）、清除空格、去除底纹、去除表格线。
- 表格宽度：一栏与多栏页面的目标宽度（默认 15 与 7 厘米，保存在本机）、读取当前表格、执行调整、表格左对齐 / 居中 / 右对齐。
- 全文：删除空行、一键去色。

窗格顶部显示操作范围。选中内容时只处理所选内容。未选中时，首行缩进和居中对齐只改光标所在段落，批量排版作用于全文。清除格式须先选中内容。每项操作执行后报告处理数量，一次撤销可恢复。

删除空行会跳过表格内、分节符所在、文档最后一段，以及两个表格之间的空行（删除后表格会合并）。清除空格删除全角空格和单元格首尾空格，英文或数字之间保留一个半角空格。一键去色把图片改为灰度、图形颜色改为灰色，浮动图形只在未选中内容时处理。

表格宽度按表格所在页面的分栏数选择一栏或多栏的目标宽度。整张表使用同一比例缩放单元格，保留列宽比例和合并结构。已是目标宽度的表格和嵌套表格的单元格不动。含宽度不确定单元格的表格会跳过并计数。“读取当前表格”把光标所在表格的宽度填入对应输入框。

以上操作已通过模拟测试，尚未在真实 WPS 中验收，建议先在文档副本上使用。

## 知识库

功能区 **iPeiTu 配图 → 知识库** 打开独立的任务窗格，存放工艺工法、各类措施等通用文字片段，点击片段卡片上的“+”插入光标处。

- **分类**：按工程类别（房建施工、市政道路管网、信息化/弱电、通用措施）和章节分类，可以按标题、章节、标签或正文检索。知识库不预置正文，片段由自己维护。
- **新建**：点“新建片段”录入，或在 WPS 文档中选中文字后点“收录选中内容”。收录会保存 WPS 返回的常用字体和段落格式。跨段选区保留段落换行，完整选中的标题按大纲级别生成小标题。
- **正文写法**：每行一段；行首 `#` 加空格为小标题，`##` 为下一级。
- **插入格式**：小标题使用文档的“标题 N”样式，从“小标题从”所选的级别开始（默认标题 3）；正文使用“正文”样式并首行缩进 2 字符。
- **片段标题**：用于识别和检索片段，插入文档时只写入正文。
- **共享编辑**：打开片段编辑框时锁定该片段，其他用户可以查看和插入。保存或取消后释放编辑锁，连接中断后两分钟内自动释放。
- **限制**：表格单元格内只插入文字，不改格式。有选中文字时不插入，以免覆盖原文。
- **撤销与删除**：一次撤销可恢复插入。回收站支持恢复、单选或多选永久删除，以及清空全部片段。永久删除和清空都需确认，清空涵盖筛选之外的片段。

片段保存在所选图库目录的 `knowledge.json`，与图片素材一起备份即可。使用局域网图库时，在服务器上备份。标题样式、收录和撤销的实机结果见 [WPS 验收记录](docs/WPS.md#知识库)。

## WPS 实机自检

在 WPS 文字选择 **iPeiTu 配图 → WPS 实机自检 → 开始自检**。插件新建临时文档，使用生成的图片验证插图、换图、占位框插入与填充、知识库标题样式和表格宽度，然后保存为 DOCX 并重新打开，核对图片和占位框标记。

完成后点击「复制报告」，可复制 WPS 版本、各项结果、读数与耗时。测试文档关闭后自动清理临时文件。如果关闭或清理失败，报告会给出处理提示。窗格显示、拖放、防火墙提示和两台电脑互连仍需人工确认。

## 局域网部署

办公室里可以让一台电脑作为局域网图库服务器，其他电脑共用同一份素材和知识库。

**服务器（一台）**

1. 在这台电脑上双击 **局域网服务器.cmd**。它完成与“安装.cmd”相同的安装，并生成访问密钥，让本地图库同时接受局域网连接。
2. 窗口最后会显示本机的局域网地址（如 `http://192.168.1.10:39831`）和访问密钥。密钥保存在 `%LOCALAPPDATA%\iPeiTu\lan-access-key.txt`，只告诉需要使用图库的同事。
3. 如果其他电脑连不上，多半是 Windows 防火墙拦截。请以管理员身份打开 PowerShell，运行窗口里给出的 `New-NetFirewallRule` 命令，只对“专用网络”放行该端口。不要在公共网络上开启。

服务器本机的 WPS 直接使用本机图库，不需要填写密钥。素材、分类、回收站和知识库都保存在服务器的图库目录，备份时复制服务器的整个图库目录即可。

**客户端（其他电脑）**

1. 照常双击“安装.cmd”。
2. 打开素材库，点击顶栏 iPeiTu 旁的 **本机**，填写服务器地址（只写 IP 时使用默认端口 39831）和访问密钥，点击“连接”。按钮变为 **局域网** 即已连接，知识库窗格顶栏也会显示“局域网”。
3. 之后检索、导入、整理、插图和知识库都使用服务器上的内容。点击“局域网”，再点“使用本机图库”即可切回本机。两边的数据不合并。

**说明**

- 收藏和最近使用按每台电脑分别记录。
- 选择图片、拖入、粘贴和文件夹导入都从本机读取文件，再上传到服务器。
- 插图时，图片先下载到本机图库目录下的 `lan-cache`，再嵌入文档，所以文档在任何电脑上都能正常打开。缓存目前不会自动清理，需要时可以手动删除该文件夹。
- 浏览和插图都需要服务器在线。服务器关机时，素材库会提示无法连接；可以切回本机图库继续工作。
- 更换密钥：在服务器上删除密钥文件，再运行“局域网服务器.cmd”，然后让各客户端重新连接。关闭局域网访问：在项目目录运行 `powershell -ExecutionPolicy Bypass -File scripts\setup.ps1 -LocalOnly`。卸载时密钥会一并删除。
- 访问密钥只用来防止网段内的其他设备随意读写图库。连接使用 HTTP，不加密，只适合在可信的内网中使用。账号和角色权限属于后续的团队云图库，本版不提供。

以上功能已通过自动化测试（包括经本机局域网地址的连接、转发、缓存和导入）。两台真实电脑之间的使用和防火墙放行仍待实机验收。

## 本地图库与再次启动

导入会复制原图到 `%LOCALAPPDATA%\iPeiTu\library`，不移动或修改源文件。相同内容只保存一条素材记录，不同文件名保留为可检索别名。缩略图、索引和必要的 WPS 插入副本也保存在该目录；WebP 和带方向信息的照片会生成用于插入的 PNG。

iPeiTu 的导入、检索和插图默认使用本机回环服务，不上传素材到云端；连接局域网图库后，素材只在局域网内的服务器上保存。图库不随代码提交到仓库。

首次使用新版会把旧索引升级到版本 3，并先在图库目录生成 `index-v1-backup-*.json` 或 `index-v2-backup-*.json` 原字节备份。既有图片和素材信息保持不变，新增回收站状态；版本 1 的旧图片先归为“未分类”。未知版本或损坏索引会报错并保留原文件。升级后不要用旧服务打开同一图库。

收藏与最近记录独立保存在图库目录的 `usage.json`，重启后保留。备份图库时请复制整个图库目录；记录文件损坏会明确报错，不自动清空。

用一键安装时，登录 Windows 后本地图库自动在后台启动；如果打开 WPS 时素材库不可用，双击“启动.cmd”。手动启动时，关闭服务窗口或按 Ctrl+C 后图库暂时不可访问，下次使用时在项目目录运行 `npm start`。两种方式下已有素材都保留，不必重新导入或重复注册。

只卸载加载项注册（不停止服务、不移除自动启动）：

```powershell
npm run wps:uninstall
```

卸载后重启 WPS 生效；脚本仅移除本次注册并恢复原有同名条目，不删除图库，也不覆盖其他加载项的配置。注册与备份机制见 [WPS 说明](docs/WPS.md)。

## 当前支持范围

本版通过“安装.cmd”在本机注册并在后台运行服务（端口 `39831`）。本机服务停止时，素材库、排版工具和知识库都不可用。局域网图库只用共享访问密钥区分能否访问，不分账号和角色。目标宿主为 Windows WPS 文字，不包含 Microsoft Word、WPS 演示或在线文档适配。

插入图片时不自动调整固定表格行高、分栏、文本框、复杂嵌套表格或段落缩进；需要固定尺寸时请使用占位框。照片表（图片表格）、表格操作、背景与页面尺寸、团队云图库将按 [v0.3 路线](docs/V03-PLAN.md) 逐步交付。以上功能都已通过自动化测试，真实 WPS 中的效果仍在验收，清单见该文档末尾。

当前插入与替换支持正文及正文表格。页眉、页脚、文本框等区域会明确禁用，避免不同文字区域具有相同坐标时误判目标；替换暂不支持浮动图片、多图或包含相邻文字的选区。
