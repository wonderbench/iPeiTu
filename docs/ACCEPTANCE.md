## 审查与修复

交叉审查发现并修复了这些实际问题，已保留相应回归测试：

- Windows 大小写或目录别名可绕过素材目录与图库目录的交叠检查。
- 透明底黑色线稿生成 JPEG 缩略图后变成纯黑；现仅为缩略图铺白底，原图与插入图片保持透明。
- EXIF 方向与插入后的显示尺寸需要一致；现生成方向规范化的插入副本。
- 图片插入成功后，排版或光标处理失败不能统一提示为“插入失败”，以免诱导重复插入。
- 请求图片路径期间若文档或选区发生变化，必须中止本次插入并提示用户重新确认位置。
- 重复卸载不能删除已恢复的旧插件配置；无本次安装状态时直接退出。
- 文档切换后重新进入任务窗格时刷新宿主状态，避免旧文档名或只读状态残留。

## 复现命令

以下命令对应包含测试套件的开发版本。`Jzc` 发布分支可用 `npm run check` 检查运行代码。

```powershell
npm ci
npm run check
npm test
npx playwright install chromium
npm run test:ui
```

Windows 已安装 Edge 时，可先设置 `$env:IPEITU_BROWSER_CHANNEL = 'msedge'` 再执行 `npm run test:ui`，无需另外安装 Chromium。真实 WPS 的启动与操作步骤见 [WPS 说明](WPS.md)。
