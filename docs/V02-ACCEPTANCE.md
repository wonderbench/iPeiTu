# v0.2 验收记录

记录日期：2026-11-05。环境：Windows WPS 文字 12.1.0.29161，Node.js 24。自动化替身与真实 WPS 证据分别列出。

## 步骤 1：统一尺寸与排版

- 本地 `npm test` 44 项通过，其中 WPS 专项 28 项；覆盖固定宽度、小图放大、横竖图限高、表格宽限制、图题拆段、保全相邻正文与格式、异步切换文档/选区/story 中止，以及部分失败状态。
- Edge 浏览器流程通过：排版偏好重载、图题不跨图片沿用、损坏与不可写存储恢复，固定宽度实际传给模拟 WPS；320/420/1080px 无横向溢出。
- 独立审查额外验证：等待图片路径时切换图片和修改设置，本次插入仍使用点击时锁定的图片与参数；320×480px 的设置可滚动到保存按钮；取消不覆盖既有偏好。
- 真实 WPS：新建测试文档，输入“前文必须完整保留，后文也必须完整保留。”并设置原段落右对齐，选中前半段后插入图片。
- 设置固定宽 12cm、最大高 5cm、独立居中、普通图题；观察到前后文完整、仍为右对齐，图片及图题在中间分别居中。
- 一次 Ctrl+Z 恢复原来单段文字，Ctrl+Y 恢复图片、图题与排版。
- 保存为本机验收 DOCX 后解包核对：正文逐字保留，四个段落对齐依次为 right/center/center/right；图片尺寸约 6.456×5.001cm，保持原 568:440 比例，符合 WPS 尺寸取整误差；1 个内嵌 drawing，图题无编号字段。
- 测试 DOCX 和真实素材未提交仓库。

尚未扩大实机覆盖至标题编号、页眉/页脚、固定行高或复杂合并表格；这些范围不能由普通正文实测或对象替身推断为全部通过。
